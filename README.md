# Suzuka Pets

两款无声铃鹿手绘桌宠：轻盈的胜负服全身形象，与适合伏案陪伴的运动服半身形象。

## 无声铃鹿 · 胜负服全身手绘

栗色长发、碧绿眼眸与绿白胜负服。保留两条飘带耳饰，以柔和配色和手绘线条表现安静、轻盈的无声铃鹿。

## 无声铃鹿 · 运动服半身手绘

以运动服和半身构图表现无声铃鹿。保留长发、耳饰与温柔神情，让眨眼、挥手和伏案工作成为桌面上的小动作。
