换上红白运动服，铃鹿也变得更松弛了。半眯的绿眼睛、三角形小笑嘴、直直的栗色长发，配上粗一些的手绘线条和暖色颗粒感，构成一只只露出小小上身的桌面伙伴。

## 她的模样

**半身构图。** 大头与紧凑的运动服上身，保留手部动作和小尾巴，形成贴近桌边的陪伴感。

**左右都有记号。** 画面左侧的圆形耳饰与两条飘带、右侧的银灰菱形发夹，保持各自的位置。

**工作的小道具。** 灰绿色笔记本电脑、轻轻敲键盘的双手，以及等待时的三个小点。
