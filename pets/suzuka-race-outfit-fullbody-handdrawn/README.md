把熟悉的绿白胜负服缩成一只二头身小铃鹿。栗色长发、碧绿眼睛、深紫手套与两条耳饰飘带保留下来，柔和的配色和略带手感的线条，让她在桌面的一角也显得安静、轻盈。

## 她的模样

**全身轮廓。** 大头、短身与完整双脚，跑步、起跳和落地都有清楚的身体动作。

**熟悉的细节。** 绿白胜负服、深紫蝴蝶结、两条耳饰飘带，以及不对称的鞋饰。

**克制的表情。** 待机眨眼、抬手招呼、低头失落，以小幅动作表达不同状态。
