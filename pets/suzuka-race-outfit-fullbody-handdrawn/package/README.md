# 无声铃鹿 · 胜负服全身手绘

v1.2 · 栗色长发、碧绿眼眸与绿白胜负服。保留两条飘带耳饰，以柔和配色和手绘线条表现安静、轻盈的无声铃鹿。

本包包含可导入的 `spritesheet.png`、名称与描述等信息 `pet.json`，以及 `previews/` 中的逐动作 GIF。

图集采用 sprite v2：1536×2288 像素，8 列×11 行，单格 192×208，包含九种动作和十六个注视方向。作品版本 v1.2 与图集协议版本是两回事。

将本包交给支持 sprite v2 的桌宠应用或 Agent，读取 `pet.json` 后导入原始 PNG。是否启用由你选择；GIF 用于观看动作。

角色来自[《赛马娘 Pretty Derby》](https://umamusume.jp/character/silencesuzuka)。保留画风参考署名：[Pixiv 1621147](https://www.pixiv.net/users/1621147)。角色及参考作品权利归原权利人。
